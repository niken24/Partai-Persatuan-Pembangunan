# PPP – Ruang Bersama (Mock-up Akademik)

Website multi-halaman berdasarkan mock-up Figma yang diberikan.

## Struktur folder

```text
ppp-ruang-bersama/
├── index.html
├── tentang.html
├── program.html
├── aspirasi.html
├── kabar.html
├── artikel.html
├── pernyataan.html
├── faq.html
├── bergabung.html
├── style.css
└── assets/
    ├── images/
    │   ├── hero-ppp.jpg
    │   ├── program-lingkungan.jpg
    │   ├── program-pendidikan.jpg
    │   ├── kabar-belajar.jpg
    │   ├── kabar-lingkungan.jpg
    │   └── kabar-kepedulian.jpg
    └── js/
        └── main.js
```

## Cara menjalankan

1. Ekstrak ZIP.
2. Buka folder `ppp-ruang-bersama` di VS Code.
3. Jalankan `index.html` menggunakan Live Server.
4. Pastikan koneksi internet aktif agar Bootstrap 5 dan Bootstrap Icons dari CDN dapat dimuat.

## Catatan

- Semua halaman memakai satu file `style.css`.
- Navbar dan footer dibuat konsisten di semua halaman.
- Form aspirasi hanya simulasi front-end; belum terhubung ke database atau server.
- Gambar lokal diambil dari area foto pada screenshot mock-up yang diberikan.
- Website ini adalah mock-up akademik, bukan situs resmi PPP. Konten program dan artikel adalah contoh.
- Sebelum publikasi, verifikasi seluruh informasi dan gunakan aset gambar yang memiliki izin penggunaan.
